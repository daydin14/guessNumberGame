# Guess the Number

A simple, responsive number guessing game that runs in your browser. Choose a
range and try to find the randomly selected whole number using the clues.

## How to play

1. Choose the minimum and maximum values for the game.
2. Select **Start game**, then enter a whole-number guess within that range.
3. Use the on-page clue to find out whether your guess is too high or too low.
4. Keep guessing until you find the number. Your previous guesses stay visible.
5. Select **Choose a new range** to start another game.

## Getting started

No installation or build step is required. Open `index.html` in a web browser
to play.

## Features

- Random number generation
- Choose your own minimum and maximum values
- In-page clues and guess history
- Input validation for the selected range
- Responsive layout for desktop and mobile screens
